# Аудиогид «Петергоф» · маршрут 343Э — версия на Python

Та же программа, что в папке [`typescript/`](../typescript/README.md), только
написанная на **Python** с помощью фреймворка [Flet](https://flet.dev) (версия 1.0).
Один код на Python собирается в сайт и в приложение для Android (APK).

- **Сайт:** https://s-smk17.github.io/peterhof-audioguide/python/
- **APK для Android:** раздел [Releases](https://github.com/s-smk17/peterhof-audioguide/releases/tag/python-latest)
  → «Python APK (последняя сборка)» → файл `peterhof-audioguide-python.apk`

Что умеет — всё то же, что версия на TypeScript: следит за положением по GPS и
сам включает рассказ у каждой из 29 остановок, показывает карту маршрута,
следующую остановку, путь пешком до ближайшей остановки (если вы не на маршруте),
кнопки «Яндекс Карты» и «2ГИС», полноэкранный плеер, прогресс, светлую и тёмную темы.

**Демо-поездка** (Ещё → «Прокатиться без автобуса», ×1 / ×5 / ×20): вместо GPS
по маршруту едет точка — так можно проверить приложение дома и на сайте без GPS.
В прогресс не засчитывается.

**«Куда смотреть»:** у остановки, где есть на что посмотреть, на экране «Гид» и
на главной (пока идёт рассказ) — плашка «Смотрите в левое / правое окно».
Сторона хранится в данных (`look_side`) для поездки к метро, на обратном пути
лево и право меняются местами.

**«Прослушано»:** точка засчитывается, когда рассказ дослушан хотя бы на 80 %
(не просто при подъезде). Галочка в списке «Маршрут», строка «Прослушано N из 29»
на главной; сброс — Ещё → Данные → «Сбросить прогресс».

**Поиск остановки:** во вкладке «Маршрут» — поле «Поиск по названию»
(регистр и «ё» не важны).

**Как мы разрабатывали приложение с нейросетью** — пошаговый план со схемами
(для преподавателя и школьников): [docs/development-plan.md](../docs/development-plan.md)

## Что внутри

| Часть | Технология |
| --- | --- |
| Язык | Python 3.10+ |
| Интерфейс | Flet 1.0 — компоненты с хуками (`@ft.component`, `use_state`), как React |
| Карта | `flet-map` (flutter_map), подложка Esri Light/Dark Gray (данные OpenStreetMap и др.) |
| GPS | `flet-geolocator`; на Android — служба с уведомлением, работает с выключенным экраном |
| Звук | `flet-audio` (audioplayers) |
| Хранение настроек | `SharedPreferences` (в браузере — localStorage) |
| Сайт | `flet build web`: Python работает прямо в браузере через Pyodide |

Структура:

```
src/main.py              точка входа
src/app/app.py           вкладки, нижняя панель, мини-плеер, карта на весь экран
src/app/controller.py    связка GPS ↔ плеер ↔ прогресс (как App.tsx)
src/app/tracking.py      «на маршруте / вне маршрута», срабатывание остановок
src/app/geometry.py      геометрия маршрута: расстояния, проекция на линию
src/app/location.py      GPS: разрешения, фоновый режим
src/app/demo.py          демо-поездка: точка едет по маршруту вместо GPS
src/app/audio.py         плеер рассказов и служебных фраз
src/app/walking.py       путь пешком до остановки (OSRM), ссылки на Яндекс/2ГИС
src/app/settings.py      настройки, прогресс, поездка; хранение на устройстве
src/app/theme.py         цвета светлой и тёмной темы
src/app/screens/         Главная, Гид, Маршрут, Ещё
src/app/ui/              карта, панели, общие элементы
src/app/data/            29 остановок и линия маршрута (из typescript/src/data)
src/assets/              фото, mp3, иконка
tests/                   тесты логики (pytest)
pyproject.toml           зависимости и настройки сборки APK/сайта
```

Логика (геометрия, срабатывание остановок, поездки) перенесена из TypeScript
один в один: те же пороги (120 м — на маршруте, 250 м — сошёл), те же правила.

## Запуск на компьютере

Нужен Python 3.10 или новее. Все команды — из папки `python`:

```bash
cd python
python3 -m venv .venv
.venv/bin/pip install "flet[all]==1.0.5" flet-audio==1.0.5 flet-geolocator==1.0.5 flet-map==1.0.5 pytest

.venv/bin/flet run src/main.py          # окно на компьютере
.venv/bin/flet run --web src/main.py    # в браузере
.venv/bin/python -m pytest              # тесты логики
```

На Windows вместо `.venv/bin/` пишите `.venv\Scripts\`.

## Запуск на телефоне без сборки

Аналог Expo Go для Flet — приложение **Flet** (Google Play / App Store).

1. Телефон и компьютер — в одной Wi‑Fi сети.
2. `.venv/bin/flet run --android src/main.py` (или `--ios`) — появится QR-код.
3. Отсканируйте его в приложении Flet — аудиогид откроется на телефоне,
   изменения в коде подхватываются сами.

Фоновая геолокация в приложении Flet может не работать — для поездки
пользуйтесь собранным APK.

## Сборка APK и сайта

Собирать ничего не нужно: после каждого `git push` в `main` GitHub сам
собирает APK и сайт (`.github/workflows/` в корне репозитория). Вручную:

```bash
.venv/bin/flet build apk     # → build/apk/*.apk
.venv/bin/flet build web     # → build/web/
```

Первая сборка сама скачает Flutter, Android SDK и JDK — это долго (~2 ГБ).

## Ограничения

- **iPhone:** код и настройки для iOS есть, но собрать `.ipa` можно только на Mac.
- **Сайт:** Python загружается в браузер (Pyodide), поэтому первый запуск сайта
  дольше, чем у версии на TypeScript. Работает, пока вкладка открыта и экран включён.
  Safari на iPhone может не дать рассказу включиться самому, пока вы не нажмёте
  на экран хотя бы раз.
- **Экран блокировки:** в версии на TypeScript есть карточка плеера на экране
  блокировки; во Flet 1.0 такой возможности у плеера пока нет. Звук при этом
  продолжает играть в фоне.
- **Карта:** другая подложка, чем в TypeScript-версии (OpenFreeMap — только
  векторные тайлы, а карта Flet показывает растровые), поэтому выглядит немного иначе.
- Голос в записях пока синтезированный, английских записей нет.
